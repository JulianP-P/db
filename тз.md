## Система хранения файлов

### Введение

Система предназначена для хранения файлов без ограничения по формату, а также предоставления к ним доступа.

Сервис ориентирован на внутреннее использование, обеспечивая основу для работы с файлами в различных компонентах системы. Он предоставляет API для загрузки, извлечения и поиска файлов, абстрагируясь от деталей физического хранения данных.

Файловое хранилище хранит файлы на жестком диске. Мета-данные о файлах хранятся в базе данных.
Программный интерфейс для доступа к хранилищу представлен набором REST-методов. Аутентификация реализована по протоколу OAuth2.
Для управления хранилищем имеется консоль администратора с web-интерфейсом. 

Файловое хранилище включает в себя следующие компоненты:
- реляционная база данных для хранения атрибутов и настроек.
- REST API, включающий сервисы загрузки файлов в хранилище и его скачивания
- web-console администрирования файлового хранилища
- keycloak для аутентификации

### Описание интерфейса пользователя
Пользовательский доступ обеспечен с помощью API-методов. Тела запросов везде (кроме отдельно описанных случаев) представлены в виде json.

#### Получение токена
endpoint: /auth/filekeep/token
тип запроса: post

Входные поля

| Поле       | Значение   | Обязательность |
| ---------- | ---------- | -------------- |
| grant_type | password   | +              |
| username   | {username} | +              |
| password   | {password} | +              |

Выходные поля

| Поле         | Описание           |
| ------------ | ------------------ |
| access_token | токен доступа      |
| token_type   | тип токена         |
| expires_in   | время жизни токена |

Коды ответа

| Код | Описание на англ.языке | Описание на русском языке          |
| --- | ---------------------- | ---------------------------------- |
| 200 | ОК                     | Успешная обработка                 |
| 400 | BadRequest             | Некорректный запрос                |
| 401 | Unauthorized           | Некорректные данные учетной записи |
| 500 | Internal Server Error  | Прочие ошибки сервера              |

#### Метод загрузки файла

endpoint: /filekeep/api/files/upload
тип запроса: post

Заголовок запроса
Content-Type multipart/form-data
Authorization: Bearer {access_token}

Входные поля

| Поле | Значение                               | Обязательность |
| ---- | -------------------------------------- | -------------- |
| file | Бинарное содержание файла              | +              |
| meta | Мета-информация о файле в формате json | +              |

Мета-информация

| Поле         | Значение                        | Обязательность |
| ------------ | ------------------------------- | -------------- |
| author       | Автор файла                     | +              |
| fileName     | Имя файла                       | +              |
| descripttion | Описание файла. Формат - string | -              |


Выходные поля

| Поле       | Описание                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------- |
| status     | статус: <br>SUCCESS (код ответа 200), <br>BAD_REQUEST (код ответа 400), <br>ERROR (код ответа 500) |
| fileKeepId | UUID                                                                                               |
| createDate | Дата и время                                                                                       |

Коды ответа

| Код | Описание на англ.языке | Описание на русском языке          |
| --- | ---------------------- | ---------------------------------- |
| 200 | ОК                     | Файл успешно загружен              |
| 400 | BadRequest             | Некорректный запрос                |
| 401 | Unauthorized           | Некорректные данные учетной записи |
| 500 | Internal Server Error  | Прочие ошибки сервера              |

#### Метод скачивание файла

endpoint: /filekeep/api/files/{id}
тип запроса: get

Заголовок запроса
Authorization: Bearer {access_token}

Входные поля

| Поле       | Значение | Обязательность |
| ---------- | -------- | -------------- |
| fileKeepId | UUID     | +              |

Выходные поля

| Атрибут | Описание                |
| ------- | ----------------------- |
| Файл    | Файл в бинарном формате |

Коды ответа

| Код | Описание на англ.языке | Описание на русском языке          |
| --- | ---------------------- | ---------------------------------- |
| 200 | ОК                     | Успешная обработка                 |
| 400 | BadRequest             | Некорректный запрос                |
| 401 | Unauthorized           | Некорректные данные учетной записи |
| 404 | Not Found              | Запрашиваемы файл не найден        |
| 500 | Internal Server Error  | Прочие ошибки сервера              |

#### Метод поиска файла
endpoint: /filekeep/api/files/search
тип запроса: post

Заголовок запроса
Authorization: Bearer {access_token}

Входные поля

| Поле           | Значение                                        | Обязательность |
| -------------- | ----------------------------------------------- | -------------- |
| author         | Автор файла                                     | -              |
| fileName       | Имя файла                                       | -              |
| createDateFrom | Поиск файла с датой <br>загрузки с данной даты  | -              |
| createDateTo   | Поиск файла с датой <br>загрузки до данной даты | -              |


Выходные поля

| Поле | Значение                                |
| ---- | --------------------------------------- |
| list | Json-список со всеми найденными файлами |

| ------------ | ------------------------------- |
| author       | Автор файла                     |

| descripttion | Описание файла. Формат - string |
| fileKeepId   | UUID                            |
| createDate   | Дата и время                    |

Коды ответа

| Код | Описание на англ.языке | Описание на русском языке          |
| --- | ---------------------- | ---------------------------------- |
| 200 | ОК                     | Успешная обработка                 |
| 400 | BadRequest             | Некорректный запрос                |
| 401 | Unauthorized           | Некорректные данные учетной записи |
| 500 | Internal Server Error  | Прочие ошибки сервера              |

### Опции, реализованные в консоли администратора
В консоли администратора с web интерфейсом будет возможность:
- изменить место для размещения загружаемых файлов
- посмотреть кол-во запросов к сервису
- посмотреть кол-во запросов к бд
- статистика по размерам загружаемых файлов

### Оценка предполагаемой нагрузки
Предполагаемая нагрузка

| Операция              | Количество операций в час |
| --------------------- | ------------------------- |
| Загрузка файла (5 мб) | 250                       |
| Выгрузка файла(5 мб)  | 250                       |
| Поиск файла           | 250                       |

### Пути масштабирования сервиса
- Вертикальное масштабирование с помощью увеличения ресурсов конкретного сервера
- Горизонтальное масштабирование с помощью создания еще одной ноды с приложением и добавлением балансировщика.
